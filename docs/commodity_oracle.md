# 원자재 오라클 통합 시나리오 모델

이 모델은 하나의 공격 수익식을 세 자산에 반복 적용하지 않습니다. WTI·천연가스·토큰화 금이 각각 다른 종류의 가격 공백을 만들기 때문에 입력과 출력도 분리합니다.

## 1. WTI 시간 공백

### 상태기계

디스커버리 바운드는 기준가 `r`, 밴드 `b`, 상방 리셋 횟수와 하방 리셋 횟수를 상태로 가집니다.

```text
하한 = r(1-b)
상한 = r(1+b)
유효 마크 = clamp(입력 가격, 하한, 상한)
트리거 = 밴드의 90%
```

트리거에 도달하고 해당 방향의 리셋 예산이 남아 있으면 기준가가 현재 경계로 이동합니다. 상·하방 카운터는 독립적이며 외부 세션 재개 시 모두 초기화합니다. 따라서 최종 입력가격만으로 결과를 계산할 수 없습니다.

상방 하드캡과 하방 하드캡은 다음과 같습니다.

```text
상방 = r0(1+b)^(리셋+1)
하방 = r0(1-b)^(리셋+1)
```

WTI의 `b=5%`, 리셋 2회에서는 기준가 100으로부터 `115.7625`와 `85.7375`가 재현됩니다.

### 마진

기본 티어의 유지증거금률은 선택 레버리지가 아니라 시장 최대 레버리지 `Lmax`에서 고정됩니다.

```text
유지증거금률 = 0.5 / Lmax
선택 레버리지 L의 청산 역행폭 = 1/L - 유지증거금률
```

WTI에서 20배·10배·5배 포지션의 청산 역행폭은 각각 2.5%, 7.5%, 17.5%입니다. 이 차이 때문에 정적 5% 밴드는 모든 포지션을 보호하지 않고 중간 레버리지 구간만 선택적으로 보호합니다.

### 골든 케이스

```text
CME 금요일 종가: 91.35
관측 온체인 마크: 95.833
CME 재개가: 106.89
관측 인식 이동: 4.91%
실제 재개 이동: 17.01%
미인식 격차: 12.10%p
```

리앵커는 이 사건 당시 활성화되지 않았습니다. 리셋 2회를 적용한 15.76%는 반드시 반사실로 해석합니다.

## 2. 천연가스 벤치마크 공백

온체인 계약이 추적하는 헨리허브와 사용자가 실제로 노출된 아시아 LNG 가격을 분리합니다.

```text
벤치마크 격차 = 목표 벤치마크 변화율 - 온체인 프록시 변화율
가정 명목의 추적오차 = 명목 × 벤치마크 격차
```

입력 원장의 사건에서는 JKM `+82.8%`, Henry Hub `-9.1%`로 격차가 `91.9%p`입니다. 명목금액 환산은 민감도 분석을 위한 C등급 가정이며, 공격자의 실현 수익이나 프로토콜 손실로 부르지 않습니다.

천연가스는 격리마진으로 입력되어 손실 경로를 `시장가 청산 → ADL`로 분기합니다. WTI·금의 교차마진 경로에는 백스톱 청산인 단계가 추가됩니다.

## 3. 토큰화 금 가격 계층 공백

### 두 개의 임계

```text
청산 개시 갭 = 1 - Max LTV / Liquidation Threshold
프로토콜 결손 완충 = 1 - Liquidation Threshold × (1 + Bonus)
```

입력값 70%, 75%, 6%에서는 각각 `6.67%`와 `20.50%`입니다. 전자는 최대 LTV 사용자의 담보가 청산되기 시작하는 지점이고 후자는 담보가 청산 인센티브까지 감당하지 못하는 지점입니다.

### 청산인 참여

```text
잔여 마진 = 청산 보너스 - 토큰 할인율
```

이는 슬리피지·재고 위험·가스비를 차감하기 전 상한입니다. 관측 최대 할인 4.5%에서는 1.5%가 남고, 할인율이 보너스 6%에 도달하면 모델은 청산인의 경제적 참여를 중단시킵니다.

### 유동성 비교

검증 규칙상 기준일이 다른 달러 금액의 비율을 만들지 않습니다. 2025년 6월 유동성 스냅샷에서 6% 가격영향 안에 처분 가능한 수량은 2,800토큰이고 공급 한도는 5,000토큰이므로 동일 시점 수량 비율은 `1.79배`입니다.

현재 가격으로 다시 평가한 공급 한도는 별도로 출력하지만 과거 유동성 비율에는 사용하지 않습니다.

## 4. 증거 등급과 재현성

`data/commodity_oracle/verified_inputs.json`만이 실행 입력의 단일 원천입니다. 각 레코드는 다음 필드를 가집니다.

```text
value, unit, definition, grade, source, as_of
```

C등급 가정은 `label=assumption`과 `sensitivity=[low, high]`가 반드시 있어야 하며 X등급 입력은 엔진에서 읽을 수 없습니다.

## 5. 코드가 주장하지 않는 것

- 실제 WTI 사건에서 ADL이나 결손이 발생했다고 주장하지 않습니다.
- 천연가스 추적오차를 공격자 수익으로 간주하지 않습니다.
- 상장 심사 시점 금 파라미터를 현행값으로 표시하지 않습니다.
- 공개되지 않은 마진 티어나 실제 거래소 매칭 엔진을 추정하지 않습니다.
