# 원자재 오라클 모델의 한계와 반증 조건

## 아직 구현하지 않은 범위

- 거래소별 마진 티어: 공개된 티어 구간이 없어 기본 티어만 계산합니다.
- 실제 청산 주문장과 백스톱 체결: 코드의 손실 폭포는 순서를 표현하며 거래소 전체를 복제하지 않습니다.
- 실제 ADL 발동 여부: 제공된 사건 자료는 청산 규모까지 확인되지만 ADL과 결손 규모는 확인되지 않았습니다.
- 휴일·조기마감 캘린더: 단일 사건은 재현하지만 연간 노출 계산은 아직 지원하지 않습니다.
- 선물 롤 혼합: 롤 창을 지나는 원시 표본이 없어 구현하지 않았습니다.
- 원유·천연가스 원시 틱과 전체 실측 갭 분포: 현재 WTI 확률모델은 제공된 두 스트레스 사건의 재표본추출이고, 천연가스는 벤치마크 비교입니다.
- 완전한 제로섬 거래소 상태: ADL은 계약 수량 기반의 제한된 연구 할당기로 구현했습니다.

## 주장 강도 제한

- `ADL이 발생했다` 또는 `결손이 발생했다`고 주장하지 않습니다.
- 리앵커는 WTI 사건 이후 도입됐으므로 사건 대입값을 반사실로 표시합니다.
- 천연가스의 달러 환산값은 가정한 명목금액에 대한 추적오차이며 공격 수익이 아닙니다.
- 토큰화 금 파라미터는 상장 심사 스냅샷이며 현행 온체인 값으로 표시하지 않습니다.
- 공격경제 몬테카를로의 성공률은 선언된 표본·가정에 조건부이며 연간 또는 무조건부 공격확률이 아닙니다.
- 천연가스는 공격자가 통제하는 행위가 확인되지 않아 공격 성공확률을 계산하지 않습니다.

## 기준시점 정합성

공급 한도 5,000토큰을 이후 시점의 금 가격으로 환산한 금액과 2025년 6월 유동성 측정값 944만 달러를 바로 나누면 시점이 섞입니다. 따라서 모델의 `supply_cap_to_capacity`는 동일 유동성 스냅샷에서 측정된 수량 `5,000 / 2,800 = 1.79배`를 사용합니다.

현재 가격으로 평가한 공급 한도 금액은 별도 필드에 보존하지만 과거 유동성 대비 비율에는 사용하지 않습니다.

## 주요 반증 조건

다음이 확인되면 해당 결론을 수정해야 합니다.

1. 공시 밴드가 `1 / 최대 레버리지`와 달라지는 경우
2. 유지증거금이 선택 레버리지 또는 공개되지 않은 마진 티어에 의해 결론을 뒤집는 경우
3. WTI 사건 원시 체결가가 입력 원장의 종가·재개가와 다른 경우
4. 주말 가격 이동이 재개 후 지속되지 않고 반복적으로 되돌아오는 경우
5. 아시아 LNG 벤치마크를 직접 참조하는 충분히 유동적인 온체인 계약이 생기는 경우
6. 2차 시장 토큰 보유자가 실질적으로 즉시 상환할 수 있게 되는 경우
7. ADL 사용자 손실이 실제 슬래싱 또는 직접 보상 사유로 연결되는 경우

## 검증을 확장할 때 필요한 자료

1. 거래소 원시 틱과 장소별 마지막 외부 기준가
2. 이벤트 당시 마진 모드·티어·리셋 설정 스냅샷
3. ADL·백스톱의 실제 체결 내역
4. 선물 만기와 롤 가중치
5. 휴일과 조기마감을 포함한 거래소 캘린더
6. 천연가스 선물 기준 주말 갭 분포
7. 토큰화 금의 현행 온체인 파라미터와 규모별 실매도 견적
