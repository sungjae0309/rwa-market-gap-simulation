# 원자재 공격경제·몬테카를로 모델

> **상태: 초기 실험 모델.** 재현과 비교를 위해 보존하지만 성공확률·배포자 공격·CVaR 결과를 연구 결론으로 사용하지 않습니다. 검토 반영본은 [`reviewed_commodity_economics.md`](reviewed_commodity_economics.md)를 사용합니다.

이 모듈은 기존 원자재 메커니즘 계산 위에 공격자의 비용(CoC), 이익(PfC), 순이익과 성공확률을 추가합니다. 모든 결과는 입력 원장에 적힌 사건 표본과 가정을 조건으로 한 연구 결과이며 무조건부 현실 확률이 아닙니다.

## 공통 회계

```text
순이익 = PfC - CoC
공격 성공 = 공격을 실행했고 순이익 > 0
```

CoC에는 실제로 소비되거나 잃은 금액만 넣습니다. 단순히 예치한 증거금은 손실이 아니므로 `capital_at_risk`로 별도 출력하고, 역방향 손실 또는 슬래싱이 발생했을 때만 CoC로 들어갑니다.

출력 지표는 다음과 같습니다.

- 기대 PfC, 기대 CoC, 기대 순이익
- 실행확률, 성공확률, 손실확률
- 순이익 5·50·95 분위수
- 95% VaR와 최악 5% 평균손실(CVaR)
- 평균 위험자본

## WTI 전략적 거래

공격자는 주말 온체인 가격이 가리키는 방향으로 포지션을 잡고, 외부시장 재개 시 아직 반영되지 않은 가격 차이를 수익 기회로 봅니다.

```text
PfC = 포지션 명목 × 미반영 갭             (방향이 맞은 경우)
CoC = 수수료 + 슬리피지 + 펀딩 + 자본비용
      + 역방향 손실 + 실제 발생한 자기본드 슬래싱
```

미반영 갭은 제곱근 시간가정으로 만들지 않고, 제공된 두 WTI 스트레스 주말을 직접 재표본추출합니다.

```text
1차 사건: (75.00 - 70.64) / 70.64
2차 사건: (106.89 - 95.833) / 95.833
```

기초시장 종가를 공통 분모로 계산한 `12.10%p`는 가격 인식 누락입니다. 실제 포지션 수익률은 공격자의 진입 마크를 분모로 계산해야 하므로 2차 사건에서는 `11.54%`입니다.

방향 일치확률 `89.9%`는 199개 심볼-주말 관측치에서 가져옵니다. 따라서 출력 성공률은 **두 스트레스 사건과 해당 연구기간에 조건부**이며 평상시를 포함한 연간 공격확률이 아닙니다.

두 행위자도 분리합니다.

1. `strategic_trader`: 시장 규칙 안에서 가격 공백을 거래하며 본드 비용이 없습니다.
2. `market_deployer`: 파라미터 결정권을 악용한다는 가정 아래 자기자본으로 부담한 본드의 슬래싱 위험도 포함합니다.

배포자의 자기본드 비중과 슬래싱 확률은 확인된 사건값이 아니므로 C등급 가정입니다.

## 토큰화 금 담보 차입·디폴트

공격자는 금속 오라클 가격보다 할인된 토큰을 매수하고, 정체된 오라클 가치로 대출을 받은 뒤 담보를 포기한다고 가정합니다.

```text
PfC = 수령한 대출금
CoC = 할인된 토큰 매입비용 + 체결비용 + 이자 + 가스·운영비
```

관측 할인 범위는 0~4.5%이고 최대 LTV는 70%입니다. 따라서 비용이 전혀 없더라도 단순 디폴트의 기본 손익분기 할인율은 약 30%입니다. 실행비용까지 포함한 기본값의 손익분기 할인율은 약 30.5%입니다.

현재 관측 범위에서는 모든 몬테카를로 시도가 손실이므로 성공확률이 0%로 나오는 것이 정상입니다. 이는 시나리오가 존재하지 않는다는 뜻이 아니라, **관측된 괴리만으로는 해당 공격형이 경제적으로 성립하지 않는다**는 반증 결과입니다.

## 천연가스

JKM과 Henry Hub의 91.9%포인트 차이는 큰 헤지 실패지만, 제공 자료에는 공격자가 가격·오라클·프로토콜을 통제하여 그 차이를 프로토콜 손실로 바꾸는 행위가 없습니다.

따라서 코드는 다음과 같이 처리합니다.

```text
classification = benchmark hedge failure
attack_success_probability = None
```

확률이 없다는 것은 0%라는 뜻이 아니라, 현재 근거로 공격 성공확률을 정의할 수 없다는 뜻입니다.

## 아직 필요한 실측자료

- 전체 WTI 주말 갭 원시 표본: 현재 성공률은 두 스트레스 사건 조건부
- 계정별 수수료·슬리피지·펀딩 기록
- 실제 배포자 자기본드 비중과 슬래싱 판례
- 금 토큰 할인율의 시간대별 원시 시계열과 실행 가능한 호가 깊이
- 천연가스 공격으로 분류할 수 있는 명시적인 통제행위와 손실 귀속 경로

이 자료가 확보되면 C등급 가정을 B 또는 A등급 실측치로 교체해야 합니다.
